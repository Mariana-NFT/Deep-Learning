This is a repository with my school assignments and capstone projects of my  AI/ML studies at the University of Texas, Austin. 

You can use them for your own learning process. You can also suggest improvements. 

1. Heart disease notebook demonstrates a neural network built from scratch using NumPy arrays. It illustrates forward and backward propagation through a largely manual process and compares this approach with the use of libraries. 
Analysing the structure of a raw neural network is important, as it helps you understand the underlying mechanisms and enables you to scale the network and transition seamlessly to other models.

2. Case study Advanced Analysis of Backward propagation self explains in the title. I added gradient analyses and compared different models against a baseline. 

3. Study Image Classification explores Convolution Neural Networks and hyperparameter tuning, and also presents transfer learning using VGG16. 

4. Churn prediction is an exercise using ANN model and SHAP analysis to extract feature importance. 

5. NLP Ticket classification is an exercise showing how to use Llama from Hugging Face to build a "chatbot" that reads complaint tickets and sends a response to the client. 

The use cases and model exploration will grow, stay tuned.
